## Complete Setup & Environment Guide

### 1. System Requirements

| Host | Operating System | Minimum Python | Required OS Utilities |
| :--- | :--- | :--- | :--- |
| **Laptop (Client)** | Ubuntu 20.04 / 22.04 / 24.04 | **3.8+** | `rsync`, `openssh-client`, `util-linux` (`lsblk`), `findmnt`, `iproute2` |
| **Desktop (Server)** | Ubuntu 20.04 / 22.04 / 24.04 | **3.8+** | `rsync`, `openssh-server`, `sqlite3`, `ufw` |

---

### 2. Desktop Environment Provisioning

Run these commands on your **Desktop**:

```bash
# 1. Install required system packages
sudo apt-get update
sudo apt-get install -y openssh-server rsync sqlite3 ufw

# 2. Run the automated desktop user setup script
sudo bash scripts/setup_desktop_user.sh
```

---

### 3. Laptop Environment Provisioning

Run these commands on your **Laptop**:

```bash
# 1. Install required system packages
sudo apt-get update
sudo apt-get install -y python3 python3-venv python3-pip rsync openssh-client util-linux

# 2. Setup the Python Virtual Environment (.venv)
cd /path/to/backup-project
python3 -m venv .venv

# 3. Activate the virtual environment
source .venv/bin/activate

# 4. Upgrade pip and install optional TUI dependencies
pip install --upgrade pip
pip install -r requirements.txt

# (Optional) Install development & testing tools:
# pip install -r requirements-dev.txt

# 5. Establish passwordless SSH trust to the Desktop
bash scripts/setup_ssh_keys.sh
```

---

### 4. Verification Check

Ensure the Python environment and system binaries are working:

```bash
# Check Python environment
python3 -c "import sys; print(f'Python {sys.version} ready.')"

# Verify system binaries exist in PATH
which rsync ssh lsblk findmnt df

# Run the test suite inside the environment
python3 -m unittest discover tests/
```
